# 🗺️ Dungeon Cartographer

A web-based tool for generating printable dungeon maps for D&D and other TTRPGs.

## 🎲 Features

- **One-Click Generation**: Generate a complete dungeon map instantly
- **D4 Direction**: Rooms expand in random directions (North, East, South, West)
- **D20 Room Types**: Different room types with visual indicators:
  - 👑 Boss Chambers
  - 💰 Treasure Hoards
  - ⚠️ Traps
  - 🏪 Shops
  - 👹 Monster Lairs
  - 🧩 Puzzle Rooms
  - ⬜ Empty Chambers
- **Printable**: Optimized print styles for physical maps
- **Export**: Save maps as JSON for later use
- **Legend**: Clear visual legend for all room types

## 🚀 Usage

1. Open `index.html` in your browser
2. Click "Generate Dungeon" or press `Enter`
3. View your dungeon map
4. Click "Print Map" or press `Ctrl+P` to print
